## What I care about

<table>
<tr>
<td width="50%" valign="top">

### Architecture

- Pragmatic design over unnecessary complexity
- Business rules that live on the server
- Data models that hold up as the product evolves
- Clear boundaries between modules and integrations

</td>
<td width="50%" valign="top">

### Security

- Authentication and authorization done properly
- Permission-based access control
- Secrets kept out of the codebase
- Validation at the API boundary

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Production reliability

- Automated, repeatable deployments
- Containerized environments on Linux/VPS
- Debugging and incident resolution in production
- Reverse proxy, domains and environment configuration

</td>
<td width="50%" valign="top">

### Maintainability

- Code the next engineer can understand
- Schema changes through migrations
- Typed contracts from database to interface
- Systems that keep evolving after launch

</td>
</tr>
